# BetKeyper launch marketing plan

Owner: the **marketing-manager** agent (`.claude/agents/marketing-manager.md`), reporting to James. Nothing is spent or published without James's yes.

## Phase 0: Before launch (now)
- [x] Slogan and voice locked (`docs/MARKETING.md`).
- [x] Link-preview ad for shared links (`public/og-image.png`).
- [x] In-app sharing: cards for every ticket + Give 25 / Get 25 invites.
- [ ] Landing page on betkeyper.com (what it is, screenshots, Try it free, 21+ footer, privacy & support links).
- [ ] Ad creative pack v1: 3 static ads × 3 sizes (feed square, feed portrait, story/vertical) + 3 TikTok / Reels scripts.
- [ ] Ad copy sets for Meta, TikTok and Reddit (3 hooks / 3 texts / 3 headlines each).
- [ ] Check each platform's current gambling-related ad policy and what approval is needed (Meta written permission, TikTok review, Reddit restrictions); write up what's allowed.
- [ ] Tracking: UTM tags per channel and ad, so sign-ups can be traced back to their source.

## Phase 1: Launch week (App Store live)
- [ ] Apple Search Ads on "bet tracker", "parlay tracker", "sports bet tracker" (small daily budget).
- [ ] Reddit: a transparent founder post where the rules allow, then small promoted posts.
- [ ] Meta and TikTok: small test campaigns (e.g. $10–20/day each), 21+, legal-betting states only.
- [ ] Organic: TikTok / Reels / Shorts from the scripts; Sunday sweat and bad-beat-of-the-week posts.

## Phase 2: Scale what works
- [ ] Weekly results review: cost per sign-up by channel and ad; pause losers, scale winners.
- [ ] Referral push: remind active users about Give 25 / Get 25 after a win.
- [ ] Email / text (opted-in users only): weekly recap, new features, plan offers.

## Budget guardrails
- Start small; no channel over its test budget until it beats the target cost per sign-up.
- Target cost per sign-up: set once real conversion data exists. Free users cost us up to $0.25 in their first month (`docs/PRICING.md`).
