# BetKeyper voice & copy

## The line
**Every ticket. Every book. One place.**
Always written exactly like this: three short sentences, each ending in a period, capital E / E / O. It leads every ad, preview and store listing. Never reword it.

## Supporting lines (pick one, don't stack them)
- **Track every bet you place, free.** (the offer; use with the slogan)
- **Snap any ticket. Sweat it live. See your real record.** (what it does)
- **Works with every sportsbook.** (never name the books in ads: trademarks)

## Voice
- Talks like a friend at the sportsbook window: short, confident, a little funny.
- Celebrates wins, laughs at bad beats, never shames losses.
- Plain words: "bet uploads", not "AI scans"; "ticket" or "slip", not "wager record".
- Always honest: BetKeyper tracks bets you already placed. It never takes bets. 21+.

## Share messages (in the app)
| Moment | Message |
|---|---|
| Win | Cashed this one. 💰 |
| Bad beat (one leg away) | One leg away. Brutal bad beat. 😩 |
| Bad bet (nothing hit) | Not one leg hit. Bad bet. 🤡 |
| Other loss | Took an L on this one. 💀 |
| Open | Locked in. 🎟️ |
| Live | Sweating this one live. 🔥 |
| Push | Pushed this one. 🤝 |
| Plain invite | I track all my bets on BetKeyper. |

Every one continues: **"Every ticket. Every book. One place. Track yours free on BetKeyper."** plus, when the person has an invite code, **"Join with my link and we both get 25 free bet uploads:"** and the link.
